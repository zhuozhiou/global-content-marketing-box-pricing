## 公开口径与产出说明

- 产出数量按当前轻量基础规格估算，并假设套餐内全部额度只用于图片或只用于视频；混合使用、选择更高质量、增加输入素材或延长视频时，实际数量会相应变化。
- 每次提交任务前，产品会显示本次预计额度，客户以提交时显示为准。
- 对外不展示具体模型名称、模型扣分、供应商、采购成本、毛利、Token、渠道政策或分成条款；上述内容仅记录在内部定价资料。
